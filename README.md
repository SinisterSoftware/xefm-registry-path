# xefm-registry-path

[XeFM](https://github.com/crftwr/xefm) extension: browse the Windows Registry read-only as `reg://` folders (keys = folders, values = files), with type / data columns and an action to open the current key in regedit (UAC prompt; Alt-Shift-Q).

XeFM 1.12.0+ / Windows only.

```
xefm ext install github:SinisterSoftware/xefm-registry-path
```

Messages follow the Windows display language. See [README.ja.md](README.ja.md) for detailed behavior and limitations, including regedit navigation.

---

XeFM 用拡張: Windows レジストリを `reg://` で読み取り専用に閲覧します。型・データ列、現在のキーを regedit で開くアクション (Alt-Shift-Q) 付き。
